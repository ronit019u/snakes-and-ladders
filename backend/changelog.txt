Fixed missing inventory field when creating new players

Fixed CSV upload leaving extra quotes around fields

Fixed question bank upload replacing the entire bank instead of appending

Fixed uploaded count returning the number of parsed rows instead of actual new questions added

Fixed earthquake preset reading field frequency mismatch with database field interval

Fixed file upload middleware being mounted after routes, causing parse failures

Replaced placeholder snake and ladder movement logic with the actual mapping table

Added completedAt field initialization when creating a session

Added completedAt write on all victory paths to record game end time
